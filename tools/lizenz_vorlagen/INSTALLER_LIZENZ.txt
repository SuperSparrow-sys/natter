Natter – Lizenzbedingungen
==========================

Die folgenden Bedingungen gelten für die Nutzung von Natter.


1. Natter selbst
----------------

Natter ist eine Entwicklungsumgebung für den Informatikunterricht. Die
Software wird unentgeltlich und ohne Gewährleistung überlassen. Eine
Haftung für Schäden aus der Benutzung ist ausgeschlossen, soweit das
Gesetz es zulässt.

Die vollständige Lizenz steht nach der Installation in der Datei
LICENSE im Installationsordner.


2. Mitgelieferte Bibliotheken
-----------------------------

Damit auf dem Rechner nichts weiter eingerichtet werden muss, bringt
Natter eine eigene Python-Installation und eine Reihe freier
Bibliotheken mit. Sie behalten ihre eigenen Lizenzen:

  * Qt für Python (PySide6, Shiboken6)  –  LGPL-3.0
  * Python selbst                       –  Python Software Foundation
                                           License
  * NumPy, pandas, SciPy, scikit-learn,
    joblib, threadpoolctl, contourpy,
    cycler, kiwisolver                  –  BSD-3-Clause
  * matplotlib                          –  Python Software Foundation
                                           License
  * SQLAlchemy, jsonschema, libcst,
    debugpy, openpyxl, jedi, ruff,
    Pillow, fontTools und weitere       –  MIT und vergleichbare
                                           freizügige Lizenzen
  * cryptography                        –  Apache-2.0 oder BSD-3-Clause
  * PyInstaller                         –  GPL-2.0 mit der Ausnahme für
                                           erzeugte Programme

Die vollständigen Lizenztexte aller mitgelieferten Bibliotheken liegen
nach der Installation im Ordner „Lizenzen".

Zur LGPL-3.0 (PySide6/Qt): Die mitgelieferte Qt-Bibliothek darf durch
eine eigene Fassung ersetzt werden. Die dafür nötigen Dateien liegen
unter python\Lib\site-packages\PySide6.

Zu PyInstaller: Es dient dem Menüpunkt „Projekt → Als Exe
exportieren". Seine Lizenzausnahme erlaubt ausdrücklich, damit
erzeugte Programme frei weiterzugeben – ein Schülerprojekt, das als
Exe exportiert wurde, unterliegt also nicht der GPL.


3. Was installiert wird
-----------------------

Im gewählten Ordner entstehen:

  * Natter.exe   –  das Programm
  * python\      –  eine eigene Python-Installation, die nur zu Natter
                    gehört. Eine bereits vorhandene Python-Installation
                    auf dem Rechner bleibt unverändert.
  * Lizenzen\    –  die Lizenztexte aus Abschnitt 2
  * dazu die Beispielprojekte und die Hilfeseiten

Es werden keine Daten an Dritte übermittelt. Natter braucht keine
Internetverbindung – außer beim Nachinstallieren zusätzlicher
Python-Pakete über das Menü „Pakete".


Mit „Ich akzeptiere die Vereinbarung" gelten diese Bedingungen als
angenommen.
